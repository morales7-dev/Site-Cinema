 CineAluga

Projeto prático de site de locadora online feito para a aula do SENAI.

 Páginas do site
- Início: apresentação e destaques
- Catálogo: filtro de filmes, séries e lançamentos com JavaScript
- Simulador: cálculo de diárias com 20% de desconto a partir de 3 dias
- Cadastro: formulário com validação de campos
- Sobre: informações do projeto

 Tecnologias
- HTML, CSS e JavaScript
